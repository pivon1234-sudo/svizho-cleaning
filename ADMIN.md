# Адмінка сайту

Адмінка — це **Decap CMS** за адресою `https://<ваш-сайт>/admin`.
Через неї можна змінювати тексти, ціни, контакти, чек-лист, кроки й питання без коду.

**Як це працює:** ви натискаєте «Опублікувати» в адмінці → Decap робить коміт у GitHub (гілка `main`) → Netlify бачить коміт, запускає `node build.js` і за ~1 хвилину публікує оновлений сайт.

```
Адмінка (/admin) ──коміт──▶ GitHub: content/*.json ──push──▶ Netlify: build.js → сайт
```

## Підключення GitHub (один раз, ~5 хвилин)

Адмінці потрібен вхід через GitHub. Netlify виступає «посередником» для цього входу, тож сервер не потрібен.

### Крок 1. Створіть OAuth-застосунок на GitHub
1. Відкрийте **GitHub → Settings → Developer settings → OAuth Apps → New OAuth App**
   (пряме посилання: https://github.com/settings/applications/new).
2. Заповніть:
   | Поле | Значення |
   |---|---|
   | Application name | `Адмінка сайту клінінгу` (будь-яка назва) |
   | Homepage URL | адреса сайту, напр. `https://kliningweb.netlify.app` |
   | Authorization callback URL | **`https://api.netlify.com/auth/done`** (саме так) |
3. Натисніть **Register application**.
4. Скопіюйте **Client ID**.
5. Натисніть **Generate a new client secret** і скопіюйте секрет — GitHub покаже його лише один раз.

> Client secret — це пароль. Не вставляйте його в код, у репозиторій чи в чат. Він вводиться тільки в Netlify (крок 2).

### Крок 2. Додайте GitHub як провайдер входу в Netlify
1. Netlify → ваш сайт → **Project configuration → Access & security → OAuth**.
2. У розділі **Authentication providers** натисніть **Install provider**.
3. Оберіть **GitHub**, вставте **Client ID** і **Client secret**, натисніть **Install**.

### Крок 3. Увійдіть в адмінку
1. Відкрийте `https://<ваш-сайт>/admin` (спочатку дочекайтесь, поки пройде деплой з адмінкою).
2. Натисніть **Увійти через GitHub** і підтвердіть доступ.

Готово. Внесіть правку → **Опублікувати** → за хвилину вона з'явиться на сайті (статус — у вкладці **Deploys** на Netlify).

## Хто може редагувати
Тільки ті, хто має право запису в репозиторій на GitHub. Щоб дати доступ іншій людині:
**GitHub → репозиторій → Settings → Collaborators → Add people**. Їй знадобиться власний акаунт GitHub.

> Якщо репозиторій приватний, на безкоштовному плані Netlify деплоїть коміти лише одного автора. Тоді коміти інших людей з адмінки не опублікуються. Публічний репозиторій такого обмеження не має.

## Що де редагується

| Розділ в адмінці | Файл | Що на сайті |
|---|---|---|
| Контакти й графік | `content/contacts.json` | назва, телефон, email, графік (шапка, підвал, сторінка «Дякуємо») |
| Перший екран | `content/hero.json` | заголовок, підзаголовок, кнопка, підказка «протріть» |
| Послуги й ціни | `content/services.json` | картки послуг **і** ціни в калькуляторі |
| Додаткові послуги | `content/extras.json` | вікна та галочки в калькуляторі |
| Чек-лист | `content/checklist.json` | таблиця «Що входить» |
| Як працюємо | `content/process.json` | кроки |
| Питання й відповіді | `content/faq.json` | FAQ |
| Пошуковики (SEO) | `content/seo.json` | заголовок вкладки й опис у Google |

Ціни тепер задаються **в одному місці** — у розділах «Послуги й ціни» та «Додаткові послуги». Калькулятор бере їх звідти.

Послуг завжди три, бо кожна відповідає колонці чек-листа. Їх можна перейменувати й змінити ціни, але не додати четверту.

## Адмінка на своєму комп'ютері (без GitHub)

Для тестування можна запустити адмінку локально. Правки тоді пишуться прямо у файли `content/`:

```bash
npx decap-server
```

В іншому вікні терміналу:

```bash
node build.js && python3 -m http.server 8000 -d dist
```

Відкрийте http://localhost:8000/admin. Після правок зберіть сайт ще раз (`node build.js`), а щоб опублікувати — `./publish.sh "що змінили"`.

## Якщо щось не так
- **«Помилка збірки» у Netlify Deploys.** `build.js` перевіряє дані й пише, що саме не так (напр. «ціна за м² має бути числом»). Виправте поле в адмінці й опублікуйте знову.
- **Після входу пише, що немає доступу до репозиторію.** Ви ввійшли акаунтом GitHub без права запису в репозиторій — див. «Хто може редагувати».
- **Вікно входу не відкривається.** Дозвольте спливаючі вікна для сайту в браузері.
- **Змінили назву репозиторію чи акаунт GitHub.** Оновіть рядок `repo:` в `admin/config.yml`.
